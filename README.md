# 같이봐요

화면 공유하면서 얼굴 보고 얘기하는 웹 앱. **HTML 파일 하나**가 전부입니다.

서비스 중인 주소: <https://imist.co.kr/meet>

## 할 수 있는 것

- 화면 공유 (PC 크롬·엣지) — 컴퓨터 소리까지 같이 전달
- 카메라 · 마이크 통화, 최대 4명
- 참여자 사진을 누르면 그 사람 **카메라를 크게** 보기, 전체화면
- 채팅, **파일 보내기** (30MB까지, 사진은 채팅에 바로 표시)
- 방장 기능 — 방장 표시, 참여자 내보내기, **방장 넘기기**
- 4자리 방 코드로 입장, 링크(`#코드`)로도 바로 입장
- 폰 전용 레이아웃 (화면/채팅 탭, 키보드가 입력칸을 가리지 않음)
- 연습 모드 — 혼자서 가상의 친구 3명과 화면을 둘러볼 수 있음

## 구조

- 영상 · 소리 · 파일은 **서버를 거치지 않고** 사람끼리 직접 오갑니다 (WebRTC, 풀메시)
- 서버가 하는 일은 처음 서로를 찾아주는 **신호 교환뿐**입니다 (Firebase Realtime Database, `sv_rooms` 경로)
- 미디어 서버(SFU)나 별도 백엔드가 없어서, 정적 파일 하나만 올리면 동작합니다

인원이 늘면 각자의 업로드가 인원수에 비례해 늘어납니다. 4명 정도가 가정용 회선에 맞는 크기입니다.

## 쓰는 법

1. `index.html` 을 **https 로 열리는 곳**에 올립니다 (GitHub Pages, Cloudflare Pages, 아무 웹 서버).
   - 카메라 · 마이크는 https 에서만 허용됩니다.
2. 접속해서 닉네임을 넣고 **방 만들기** → 나온 4자리 코드를 친구에게 보냅니다.
3. 친구는 같은 주소에서 **방 참여하기** → 코드 입력.

### 내 Firebase 로 바꾸려면

`index.html` 위쪽 설정 부분을 고치면 됩니다.

```js
const DB_URL = 'https://<내-프로젝트>-default-rtdb.firebaseio.com';
const ROOT   = 'sv_rooms';
const MAX    = 4;
```

Realtime Database 규칙은 `sv_rooms` 아래만 읽고 쓸 수 있게 열어두면 됩니다. 방 정보(참가자 목록, 연결 신호)만 잠깐 오갈 뿐 대화 내용은 저장되지 않습니다.

## 브라우저

크롬 · 엣지 · 사파리에서 동작합니다. 화면 공유는 PC 브라우저에서만 됩니다(폰은 카메라 · 마이크 · 채팅 · 파일). 카카오톡 같은 앱 안의 브라우저로 열면 카메라 권한이 막히므로, 바깥 브라우저로 열어야 합니다.
